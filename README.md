# 小岛邮局

小岛邮局是一个运行在家庭局域网里的聊天室。电脑、平板和手机用浏览器登录同一个房间，可以互发文字、图片、视频和其他文件。消息通过 Server-Sent Events 实时更新，聊天记录和附件保存在运行服务的主机上。

## 启动

在主机上安装 Node.js 22.13 或更高版本，然后在项目根目录运行以下命令。

```sh
npm ci
npm run build
npm start
```

主机可以直接[打开聊天室](http://localhost:7070)。在同一 Wi-Fi 下的其他设备上，打开终端打印的「局域网」地址。使用期间请保持主机和服务运行。若其他设备无法连接，检查主机防火墙是否允许前端端口，以及 Wi-Fi 是否启用了设备隔离。默认的 HTTP 服务适合可信局域网，跨不受信任的网络使用时应配置 HTTPS。

## 创建第一个管理员并邀请家人

全新部署的默认家庭邀请码是 **`12345678`**。这个默认值是公开的，请在开放注册前用管理员账号将它改为自己的邀请码。已有部署升级时会沿用原邀请码。

1. 服务首次启动后，在主机上另开一个终端，进入项目目录，运行 `npm run admin -- "你的用户名"`。新账号的密码会显示在终端。若账号已存在，用原密码登录即可。
2. 使用管理员账号登录，点击聊天室右上角的「家庭管理」，在「注册邀请码」中填写新码，点击「保存邀请码」即可生效。
3. 家人在登录页选择注册，填写邀请码、用户名和至少 8 个字符的密码。注册一次后，同一账号可以在多台设备上登录。在线列表按账号汇总，退出登录只结束当前浏览器的会话。

## 配置端口和管理员

编辑项目根目录的 [config.json](./config.json)，默认配置如下。

```json
{
  "frontendPort": 7070,
  "backendPort": 7071,
  "adminUsers": []
}
```

前端和后端各使用一个空闲端口。浏览器访问前端端口，API 和媒体请求会自动转发给后端。保存配置后重启服务即可，无需重新构建前端。

要授权已有账号，可将用户名填入 `adminUsers`，例如 `["小林", "阿青"]`。重启服务并刷新页面后生效。名单中的名字会被保留，无法通过网页注册。移出名单可撤销配置授予的权限。通过 `npm run admin` 单独授予的权限保存在数据库中，独立于这份名单。

## 收发消息

点击输入框下方的「文件」可发送任意类型的文件，每条消息可以附带一个文件。收件人点击文件名即可下载。应用不限制单个附件大小，上传会流式写入主机磁盘。若云服务器使用 Nginx 反向代理，需要在对应站点设置 `client_max_body_size 0;` 并重载配置，才能取消代理层的请求大小限制。“小岛相册”和“家庭影集”会汇总聊天中分享的媒体，视频能否播放取决于浏览器支持的格式。

电脑上按 Enter 发送，Shift + Enter 换行。Mac 上按 Control + Shift + Command + 4 框选截图，再到输入框按 Command + V 粘贴，确认预览后发送。

## 开发

React 和 Vite 前端位于 `frontend/`，Node.js 和 Express 后端位于 `backend/`。安装依赖后，在两个终端分别运行 `npm run backend` 和 `npm run dev`，打开 Vite 输出的地址。开发与生产共用端口配置。

## 数据与备份

SQLite 数据库 `backend/data/chat.sqlite` 保存账号、会话、邀请码和消息。附件原文件保存在 `backend/data/uploads/`。备份或迁移时，停止服务并复制整个 `backend/data/` 目录。Git 默认忽略该目录。

可用环境变量 `CHAT_DATA` 指定其他数据目录。启动服务和运行管理员命令时应使用相同的路径。如果自定义目录位于仓库内，请将它加入 `.gitignore`。兼容已有启动脚本的 `PORT` 环境变量优先于 `backendPort`，开发时请在两个终端设置相同的值。
